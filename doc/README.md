# COMPASS-namespace documents

This directory holds the Compass documents of the `COMPASS` namespace itself —
the standard's own Plans, Logs, and reference material, authored under the
standard defined in `../Compass.md`.

The follow-on Plans tracked in `Compass.md` §23 (Specified, tooling deferred)
live here as they are written:

- `COMPASS-DRAFT-toolchain` — validation toolchain + Markdown→Lexis importer (S1, S2)
- `COMPASS-DRAFT-fixture-compilation` — README/fixture transclusion (S7)
- `COMPASS-DRAFT-user-doc-derivation` — audience projection / end-user docs (S5)
- `COMPASS-DRAFT-federated-site` — federated Astro site (S8)
- `COMPASS-DRAFT-authoring-assistance` — editor tooling + LLM skills (S9)

Files follow the standard's naming (`Plan.*.md`, `Log.*.md`, `Ref.*.md`, …)
and front-matter (§7). Provisional identifiers use `COMPASS-DRAFT-<slug>` until
a steward assigns the canonical `COMPASS-<NNNN>` at merge (§13).
