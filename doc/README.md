# EIDOS-namespace documents

This directory holds the Eidos documents of the `EIDOS` namespace itself —
the standard's own Plans, Logs, and reference material, authored under the
standard defined in `../Eidos.md`.

The follow-on Plans tracked in `Eidos.md` §23 (Specified, tooling deferred)
live here as they are written:

- `EIDOS-DRAFT-toolchain` — validation toolchain + Markdown→Lexis importer (S1, S2)
- `EIDOS-DRAFT-fixture-compilation` — README/fixture transclusion (S7)
- `EIDOS-DRAFT-user-doc-derivation` — audience projection / end-user docs (S5)
- `EIDOS-DRAFT-federated-site` — federated Astro site (S8)
- `EIDOS-DRAFT-authoring-assistance` — editor tooling + LLM skills (S9)

Files follow the standard's naming (`Plan.*.md`, `Log.*.md`, `Ref.*.md`, …)
and front-matter (§7). Provisional identifiers use `EIDOS-DRAFT-<slug>` until
a steward assigns the canonical `EIDOS-<NNNN>` at merge (§13).
